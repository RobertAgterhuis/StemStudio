# Hand-off: qa / 004 US1 (T037)

## What was built

- `e2e/visual/screens.spec.ts` (project `visual`): 60 `toHaveScreenshot` cases. 7 screen states
  (import, tracks, track with detail stems, track without detail stems, mixer collapsed, mixer with
  drums expanded, mixes) x {dark, light} x {beginner, advanced, expert} = 42, plus per theme the
  welcome panel, the docked help panel on the mixer, step 1 of `import-basics`, 360 px views of
  Import, Tracks, Track, Mixes and the help sheet, and the mixer at 768 px. Full-page where the
  page scrolls; masks for meters/dB readouts, `transport-position`, `transport-state`, `toast` and
  `<time>`; motion reduced (stored preference + `reducedMotion`), animations disabled, caret
  hidden, 0.1 % pixel threshold. The file skips itself outside the Playwright Linux image
  (`/ms-playwright` present) unless `E2E_VISUAL_CONTAINER=1`.
- `e2e/tests/theme-flash.spec.ts` (`@ux`, Chromium + Firefox): 4 cases (stored dark vs OS light,
  stored light vs OS dark, system with OS dark, system with OS light) x 20 reloads; per reload
  `html[data-theme]` at `domcontentloaded` and a 1 x 1 px screenshot that must be nearer to the
  expected theme's `body` background than to the other's (both resolved to sRGB via canvas, so
  any token colour syntax works).
- Support: `support/screens.ts` (screen definitions and readiness), `support/ux-data.ts` +
  `support/ux-test.ts` (worker-scoped seeded data: band track with completed detail phase, click
  track with cancelled detail phase, mix "UX practice"), `support/visual.ts` (container guard,
  masks, matrix), `support/theme-flash.ts` (pixel decoder, background reader), page objects
  `pages/app-shell.ts`, `pages/help-panel.ts`, `pages/tour-popover.ts`.
