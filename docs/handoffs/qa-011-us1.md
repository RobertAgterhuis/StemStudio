### Tag convention (devops T059) - confirmed

Confirmed as proposed in `devops-011-us3.md`, with two additions:

1. every agent test carries `@agent`; a scripted test exactly one `@<script basename>`;
2. the unavailable test carries `@agent` **and** `@agent-unavailable` and no script tag (so
   `npm test` excludes it, and the fake passes' `--grep-invert` drops it);
3. tests needing the generator carry `@generative` too (not run by the plain fake passes);
4. `npm test` excludes `@agent` (done, also `test:legacy` and `test:generative`);
5. *addition*: tags are literal arrays (`{ tag: ['@agent', '@us1-command'] }`; ESLint
   `playwright/valid-test-tags` refuses computed tags) and checked by the self-test;
6. *addition*: no test title contains `@` (Playwright's grep also matches titles, so a title with
   `@agent` would be dropped from `npm test`).
