## Decisions

- Verify does not check free space; H16 is restore-only. `RestoreReport.migratedFrom` = the
  archive's `schema.lastMigration` when migrated (CTO decisions, 013 rows).

## For the other lanes

- **backend**: a refused restore may answer synchronously (`409`/`422` problem) or fail the job with
  `JobError.code`; the spec accepts both but the code must be the catalogued one. A verify of a
  hostile archive ends with `VerifyReport.problem.code` (or `error.code`). Skipped profiles are
  reported as `SkippedItem { category: "voiceProfiles", reason: "consent-invalid" }`.
  `GET /api/backups` lists `not-a-backup.zip` / `not-a-zip.zip` with `recognised: false`.
- **frontend**: restore dialog on an empty library renders neither `restore-mode-*` radio; the
  restore button of an `incompatible` / `unrecognised` row is disabled and `backup-row-status-*`
  carries the reason.
- **CTO run**: the hostile and state cases need `E2E_BACKUP_DIR` (or `E2E_COMPOSE=1`); the empty
  library case runs first on a fresh project (`npm run test:library-care-fresh`).
