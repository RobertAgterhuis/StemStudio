## What was built

`e2e/tests/detail-mixer.spec.ts` (`@detail`), on the plain `detail_10s_band.wav` track with a
completed detail phase (`ensureDetailCompleted`; fast on reruns through the worker cache):

| Test | Covers |
|---|---|
| only split parents expand, and expanding swaps the parent audio for its detail strips | `expand-<parent>` with `aria-expanded=false` for vocals/drums/other, none for guitar/piano; expand drums -> `strip-drums[data-expanded=true]`, `group-drums`, four strips at 80 % / pan 0 / mute and solo off with meters; `meter-drums-kick` moves, `meter-drums` falls to -60; master peak over a full 1 s loop changes by <= 1.5 dB (US2 AS1, FR-012) |
| muting the snare silences only the snare; solo kick silences every other channel | US2 AS2, AS4, FR-013 |
| detail controls reach the audio engine within 50 ms | SC-004 with the 001 AudioParam probe on `fader/mute/solo-drums-*` |
| collapsing brings the parent back and the next expansion keeps the detail settings | US2 AS3 |
| 50 loop repetitions with drums expanded mid-playback stay sample-aligned | US2 AS5, FR-014, SC-004 via `e2e/support/alignment-probe.ts`: >= 10 running stem sources, max anchor difference <= 1 ms |

Also: `MixerPage.maxPeakOver` (in-page rAF sampling of `data-peak-db`) and `measureSc004` in
`e2e/support/engine-probe.ts`, now shared by `mixer.spec.ts` and `detail-mixer.spec.ts` (removed
a duplicated block); `fakeStems`/`silentDb` exported from `support/detail.ts`.

**Deviation (layout only):** tasks.md names one file `detail.spec.ts` with sections. One
`test.describe` per section exceeded the suite's `max-lines-per-function` (60), so each section
gets its own file `detail-<section>.spec.ts`; "auto" stays in `detail.spec.ts`. All carry the
`@detail` tag, so `npm run test:detail` runs them together.

**Note on "engine debug hook":** the 001 suite has no engine-internal debug hook; it has the
AudioParam probe (ADR-008 #5). The alignment check therefore uses a second init-script probe on
`AudioBufferSourceNode.start/stop`, which observes the engine through the Web Audio API only
(no engine internals, no new contract).
