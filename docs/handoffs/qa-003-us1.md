## Deviations

- The default-suite CPU assertion lives in a new `device.spec.ts`, not in `main-flow.spec.ts`
  (T033 text). The main flow imports `music_100bpm_20s.mp3`, which on any rerun (and on a data
  volume from 002) is a cache hit, and cached results have `device = null` (data-model 2.2), so
  `track-device` would not exist. The new spec uses a per-run unique copy and therefore always
  sees a live job. The main flow is untouched.
