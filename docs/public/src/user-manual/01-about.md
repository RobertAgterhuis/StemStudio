# About this manual

This manual explains StemStudio for the people who use it: musicians who want to practise
along with a song by turning instruments up, down or off. It covers the complete product as
planned in features 001 to 011. Features that are still being built are clearly marked, so
you always know what you can use today.

## Feature status

The table below is generated from the project roadmap (`docs/ROADMAP.md`) and the status
log (`docs/STATUS.md`) each time this manual is built. A feature is **Delivered** once its
integration wave has passed all quality gates; until then it is **In development** and the
chapters describe the behaviour that has been specified for it.

## A living document

This documentation is updated continuously. Every feature that changes what you see in
StemStudio, or how StemStudio is installed and set up, must update this user manual and/or
the technical manual and regenerate both PDFs before its integration wave closes. This is a
rule of the project constitution (Governance, version 1.3.1), so the manual you are reading
always matches the delivered product. The cover shows the build date and a short fingerprint
of the sources the PDF was built from.

## How to read this manual

- Chapter 2 gets StemStudio running with one command.
- Chapters 3 to 6 cover the core of the product: experience levels, importing songs, stems
  and the mixer, and saving mixes.
- Chapters 7 to 13 describe the features that build on the core: cover art and band info,
  karaoke lyrics, the export library, sheet music, style transfer, songs from your own
  lyrics and the AI composer agent.
- Chapters 14 to 17 are reference material: keyboard shortcuts, help and tours,
  troubleshooting, and the legal notice.

Names of buttons and screens are printed in **bold**. Keys are shown like <kbd>Space</kbd>.
On a Mac, <kbd>Mod</kbd> means <kbd>Cmd</kbd>; on Windows and Linux it means <kbd>Ctrl</kbd>.

## Stem colours

StemStudio gives each of the six standard stems its own colour. The same colours are used
on the channel strips, in the track ribbons and in this manual:

<span class="stem stem-vocals">vocals</span>
<span class="stem stem-drums">drums</span>
<span class="stem stem-bass">bass</span>
<span class="stem stem-guitar">guitar</span>
<span class="stem stem-piano">piano</span>
<span class="stem stem-other">other</span>

Detail stems (for example lead and backing vocals) use the colour of their parent stem with
a different tab pattern, never a new colour.
