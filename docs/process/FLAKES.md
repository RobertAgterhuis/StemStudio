# Flake list

Every E2E test that failed and then passed unchanged gets a row here, before the next run re-tries it. Integration does not
re-run a known flake: it is fixed (root cause, proven with `--repeat-each` and `retries=0` on an isolated stack) or
quarantined with `test.fixme` and a row with status `quarantined` that names the owner of the fix. `retries` stays 0
(`docs/testing/TEST-STRATEGY.md`).
