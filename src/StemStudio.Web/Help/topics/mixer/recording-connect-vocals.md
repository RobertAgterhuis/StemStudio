- A **USB microphone** appears as its own input. A dynamic or condenser microphone goes into an **interface** input
  (condensers need phantom power, the 48V switch).
- Choose part **Vocals** so the original vocal stem is muted while you sing.
- Set the gain on the interface so loud notes stay below clip; keep a hand's width from the microphone.
- Use **headphones**: speakers would be recorded with your voice.
