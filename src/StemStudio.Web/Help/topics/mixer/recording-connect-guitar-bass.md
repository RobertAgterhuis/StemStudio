- Plug the instrument into an interface input marked **Hi-Z** or **Instrument**, or put a microphone in front of the amp.
- Choose part **Guitar** or **Bass**; the original stem is muted while you play.
- Mono is right for one instrument. From Advanced choose **mono input 1** or **mono input 2** for the input you use.
- If you hear yourself late through StemStudio, use direct monitoring on the interface instead
  ([monitoring](help:recording-monitoring)).
