The **key** of the song (for example *C major*) stands next to the tempo on the track page and in the mixer, for every
instrument. It tells you which scale to improvise in and which chords to expect. It is found together with the chords,
so it appears once chord detection is ready.

- **Key changes**: when the song changes key, the mixer shows the key of the part you hear ("Now: D major"). From
  Advanced the track page lists every key change with the bar it starts in.
- **Transpose**: with the practice transpose the key you hear is shown with the original key and the interval, for
  example "D major (original C major, +2)". Chords are spelled for that key: flats in flat keys, sharps in sharp keys.
- **Your part**: when you practise as strings / brass / woodwinds with a transposing instrument, the key of your written
  part is shown too ("Your part: A major" for an alto saxophone in a C major song).
- **How sure**: a key marked *(uncertain)* was hard to detect. From Advanced the confidence and the closest other key
  are shown, for example "81 % (or A minor)".

Limits: the key comes from the detected chords, so songs with few chords, modal songs and songs that stay on one chord
can show a relative key (A minor instead of C major) or a wrong one; check it by ear.
