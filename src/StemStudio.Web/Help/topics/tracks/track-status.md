| Status | Meaning |
|---|---|
| Queued | Waiting for the processing service |
| Downloading | Fetching the audio |
| Separating | Splitting into stems |
| Analysing | Finding the tempo and beats |
| Completed | Ready for the mixer |
| Failed | Something went wrong; the reason is shown and you can retry |
