| Format | What it is | Options (Advanced) |
|---|---|---|
| **FLAC** (default) | Lossless and compressed: the best choice for keeping a stem. | 16-bit (default) or 24-bit |
| **WAV** | Uncompressed; opens in every audio program. | 16-bit (default) or 24-bit |
| **MP3** | Lossy and small; good for a phone. | 192, 256 or 320 kbps (default) |

Every file is 44.1 kHz stereo. A raw stem saved as 16-bit FLAC is bit-identical to the stem StemStudio
separated. MP3 files carry no tags (title, cover) in this version.
