Everything StemStudio makes with AI is marked as such, so you always know what is real and what is generated:

- every take shows an **AI-generated** badge, and its details name the style, the seed, the model and the device;
- a track imported from a take shows **AI-generated** on its page and **AI** in the track list, with a link to the
  song it came from;
- the library shows the takes as generated items;
- the audio file itself carries the tags `AI_GENERATED=true` and the name and version of the generator.

The label is text, not only a colour, so screen readers announce it too.
