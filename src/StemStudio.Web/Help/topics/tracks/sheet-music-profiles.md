Each profile writes the notes the way that instrument is usually read:

| Profile | Notation |
|---|---|
| Vocals (melody) | One melody line in the treble clef; simplified rhythm by default. |
| Bass | One note at a time, bass clef written an octave higher (8vb). |
| Guitar | Treble clef written an octave higher; chords as stacked notes, no tablature. |
| Keys | Two staves split at middle C. |
| Piano | Two staves; an accurate piano model or a fast general one. |
| Drums | One percussion staff from the five drum detail stems. |

The dialog suggests the profile of the stem, for example **Bass** for the bass stem and **Keys** for "other". Pick
another when the stem holds a different instrument. Each profile shows its limits before you start.
