The journey rail is shown at Beginner level on the import, track and mixer screens.

1. **Import**: paste a link or drop a file.
2. **Separate**: wait while StemStudio splits the song into stems.
3. **Mix**: open the mixer and practise.
4. **Save**: keep your mix so you can load it again.

The current step is marked. The main button on each screen takes you to the next step.
