Open **Preferences** and choose **Change shortcuts and foot pedals**.

1. Press **Change** next to a command, then press the key you want. Escape cancels.
2. When the key already does something else, StemStudio tells you which command uses it. Change that one first.
3. **Clear** removes the key of a command. **Reset all shortcuts** brings back every default key.

Some keys can never be used because the browser or a screen reader needs them: Tab, Enter, Escape, F5, F6, F7, F11,
F12, Insert, Caps Lock, the menu key and the browser's Ctrl keys for tabs, windows, reload, print, find and zoom. Keys
the lyrics editor uses are kept for it too.

**Single-key shortcuts** (in Preferences, at every level) switches off every shortcut without Ctrl. Then a stray key press,
for example from speech input, never starts or stops the music.
