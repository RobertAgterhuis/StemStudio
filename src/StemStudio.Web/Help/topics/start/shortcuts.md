Press **Ctrl+/** (Cmd+/ on a Mac) on any screen, or **Keyboard shortcuts** in the help panel, to see the keys that work
right now. The overview shows your own keys when you changed them, and the keys of your foot pedals.

Shortcuts do not work while you type in a field, and Space or Enter on a focused button still presses that button.

The default keys:

| Keys | Action |
|---|---|
| Ctrl+K | Command palette |
| ? or F1 | Help for what you are on |
| Ctrl+/ | The shortcut overview |
| G then I, T or M | Go to Import, Tracks or Mixes |
| Space | Play or pause (mixer) |
| Home | Stop and go to the start |
| Left / Right | Seek 5 s back or forward (Shift: 1 s) |
| [ and ] | Set loop A and B at the position |
| L | Loop on or off |
| Shift+L | Loop the section that is playing |
| N / Shift+N | Next or previous section |
| Backspace | Back to the start of the section |
| K | Click on or off |
| Shift+K | Count-in on or off |
| - / = | Practice speed -5 % or +5 % |
| , / . | Key down or up one semitone |
| 0 | Original speed and key |
| T | Speed trainer on or off (Advanced) |
| F / Shift+F | Score panel on or off; score follow on or off |
| 1 to 9 | Select a channel |
| M / S | Mute or solo the selected channel |
| Ctrl+S | Save the mix (Shift: save as) |
| Ctrl+Right / Ctrl+Left | Next or previous song in a setlist |

Count-in moved from C to Shift+K and "original speed and key" from R to 0: R and C are kept for recording.
