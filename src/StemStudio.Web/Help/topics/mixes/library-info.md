**Edit library info** on a song folder changes the names used to file all items of its track; the button on an
item changes only that item. For each of artist, album and song you either type your own name (1 to 200
characters) or tick **Automatic**. The automatic name and where it comes from (band info, import or fallback) are
shown next to it. **Reset** makes every name automatic again.

- After saving, the items move at once and the library follows them to their new folder.
- Names you typed are never changed by StemStudio. Automatic names update by themselves, for example when band
  info is found later.
- If the artist or title of the track itself is wrong, use **Look up band info again** on the track page; the
  automatic names then follow the new band info.

Library info is available at every level.
