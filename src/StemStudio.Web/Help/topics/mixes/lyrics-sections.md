**Add sections** looks at the blocks of your lyrics (separated by empty lines) and puts a marker above each one: a block
that comes back is marked as the **chorus**, the others as **verses**. The text in the editor is replaced by the result,
so check it and change any marker you like. Lyrics that already have markers keep them.
