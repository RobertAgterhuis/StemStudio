StemStudio accepts:

- a YouTube video link, such as `https://youtu.be/...`;
- a Spotify track link. StemStudio reads the track details and uses a matching public YouTube video for the audio.

Playlists and albums are not supported: import one song at a time. If a link fails, the reason is shown
under the field.
