The import screen turns a song into stems.

- Paste a [link](help:import-url) and press **Import**, or
- drop an [audio file](help:import-file) on the drop zone.

StemStudio then opens the track page, where you follow the separation. It runs on the
[processing device](help:processing-device) shown under the form. Read [what can be separated](help:stem-limitations)
before you start.
